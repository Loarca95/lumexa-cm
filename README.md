# Lumexa CM

Catálogo web listo para publicar con GitHub Pages.

## Publicación
1. Sube todo el contenido de esta carpeta a la raíz del repositorio.
2. Ve a Settings > Pages.
3. En Source selecciona Deploy from a branch.
4. Selecciona branch `main` y carpeta `/(root)`.
5. Guarda y espera unos minutos.

El archivo `index.html` debe permanecer en la raíz del repositorio.
